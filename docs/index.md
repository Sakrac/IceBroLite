Ice Bro Lite is a visual debugger for the VICE C64 emulator that makes machine-level troubleshooting feel far more approachable. It brings together source, disassembly, memory, registers, watches, breakpoints, trace data and graphics in a flexible, dockable workspace.

It connects directly to VICE's Binary Monitor for core debugging data and the Text Monitor for console-based features. The latest version of VICE can be downloaded from [here](https://vice-emu.sourceforge.io/index.html#download).
